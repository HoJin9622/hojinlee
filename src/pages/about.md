## Experience

### 카카오모빌리티

2023.03 - 현재

카카오 T 앱 내 차량 관리 서비스의 웹뷰와 어드민 시스템을 개발하고 있습니다.

어드민 시스템은 설계부터 운영까지 맡고 있습니다. 운영자가 서비스를 안정적으로 관리할 수 있도록 백오피스 기능을 만들고, 개인정보보호 요구사항이나 접근성 개선, 프레임워크 업그레이드 같은 일도 함께 다룹니다.

서비스 개발 과정에서 반복되는 배포 문제를 줄이기 위해 사내 CDN SDK와 에셋 업로더 플러그인도 만들었습니다. Rolling Update 중 정적 파일 경로가 맞지 않아 발생하던 404 문제를 해결하고, 배포 중에도 안정적으로 에셋을 제공할 수 있는 구조를 만들었습니다.

인프라 영역에서는 Next.js Standalone, Multi-stage Build, CDN 정적 에셋 분리, Docker BuildX 캐시 전략을 적용해 Docker 이미지 크기와 빌드 시간을 줄였습니다.

### 어니언팜

2020.09 - 2022.10

SI/외주 프로젝트에서 앱, 웹, 백엔드, 인프라를 함께 다뤘습니다. React Native 앱 개발과 스토어 배포, Django REST API 서버 개발, AWS EC2/RDS/Route53 기반 인프라 구축, PG 결제 연동, WebRTC 화상 통화, i18n 다국어 지원 등을 맡았습니다.
